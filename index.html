vpsfort packages

The documentation: the READMEs and the comparison with other tools, as a site.

Signed apt and dnf repositories for vpsfort, its bots and the web console: the newest release of each, as static binaries for amd64, arm64 and armhf. The signing key's fingerprint: 12A75B42C4ADD340896F5E7A2F64B712E37F3CEC (compare it with the one in the repository's README, and with the downloaded key's: gpg --show-keys /etc/apt/keyrings/vpsfort.asc).

Debian, Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://makhort.github.io/vpsfort/vpsfort.asc | sudo install -m 0644 /dev/stdin /etc/apt/keyrings/vpsfort.asc
echo "deb [signed-by=/etc/apt/keyrings/vpsfort.asc] https://makhort.github.io/vpsfort/deb stable main" | sudo tee /etc/apt/sources.list.d/vpsfort.list
sudo apt update && sudo apt install vpsfort      # or vpsfort-web, vpsfort-xmpp-bot, ...

Fedora, RHEL

sudo curl -fsSL https://makhort.github.io/vpsfort/vpsfort.repo -o /etc/yum.repos.d/vpsfort.repo
sudo dnf install vpsfort

The rpms here are signed with the same key (dnf checks each package); the releases' own files are not, and carry a build provenance attestation instead.

Nothing starts on its own after an install: each package puts a config template in place and says what to fill in. An upgrade keeps the config and restarts a running service. The same packages, with their .sha256 and build provenance attestations, are on each release.
